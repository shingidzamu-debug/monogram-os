# Changelog

## V0.12 — premium pass
- Canvas to #fbfbfb; cards separated by hairline, shadow reserved for
  hover and overlays.
- Radius as hierarchy (20/12/10/pill) instead of one value everywhere.
- Type scale rebuilt: 34px/700 titles at -0.04em, tabular figures.
